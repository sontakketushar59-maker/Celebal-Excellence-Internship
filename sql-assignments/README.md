# SQL Assignments — ShopEase Analysis

This folder contains SQL queries for the ShopEase dataset.  
Each section is part of the internship assignment and explains SQL concepts step by step.

## Sections
- **Section_A — Basic Queries**  
  Simple queries to display data.  
  Example: list all customers, products, or orders sorted by name or price.

- **Section_B — Filtering Queries**  
  Queries with conditions using `WHERE`, `LIKE`, `BETWEEN`.  
  Example: find orders in a date range, or products above a certain price.

- **Section_C — Aggregation Queries**  
  Summaries using `SUM`, `AVG`, `COUNT`, `GROUP BY`.  
  Example: calculate total sales, average order value, or number of customers per city.

- **Section_D — Joins Queries**  
  Combine data across tables using `INNER JOIN` and `LEFT JOIN`.  
  Example: show customer details with their orders, or products linked to categories.

- **Section_E — Advanced Queries**  
  Use `CASE` for conditional logic and transactions with ACID principles.  
  Example: classify products into “Budget / Mid‑Range / Premium,”  
  or run a transaction that updates stock after an order.

## How to Run
1. Open each `.sql` file in MySQL Workbench.  
2. Execute queries section by section.  
3. Read the comments — they explain the logic in simple words.

## Key Learning
- Start with basics, then apply filters.  
- Summarize data with aggregation.
  
- Connect tables with joins.  
- Apply advanced logic and transactions for real‑world scenarios.
