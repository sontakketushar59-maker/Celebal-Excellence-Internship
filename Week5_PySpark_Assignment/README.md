# Week 5 - PySpark Assignment

## Overview

This assignment focuses on the basic concepts of Apache Spark and PySpark for big data processing, data cleaning, and transformation.

The notebook covers both theoretical concepts and practical DataFrame operations using PySpark.

## Topics Covered

* MapReduce limitations and Spark advantages
* In-memory computing in Spark
* Duplicate removal
* Filtering data
* GroupBy and aggregation
* Null value handling
* Spark DataFrame immutability
* Data cleaning and transformation
* Data type casting
* Timestamp handling
* Shuffle and wide transformations
* Removing invalid records
* Multiple aggregations using `agg()`
* Schema inference and data quality
* PySpark data processing pipeline

## Practical Work

The assignment includes practical PySpark operations such as filtering records, removing duplicates, handling null values, grouping data, calculating aggregations, converting date and timestamp values, and creating a basic data processing pipeline.

The Sample Superstore dataset was used for practical implementation. Some column names were adapted according to the available dataset while keeping the required PySpark logic and concepts the same.

## Technologies Used

* Python
* PySpark
* Apache Spark
* Jupyter Notebook

## Conclusion

This assignment helped me understand how Spark DataFrames can be used for data cleaning and transformation. It also improved my understanding of Spark concepts such as in-memory processing, DataFrame immutability, shuffle operations, and data processing pipelines.
