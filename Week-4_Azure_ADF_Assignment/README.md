# Week 4 - Azure ADF Assignment

## Title
Azure Cloud Fundamentals and Data Pipeline Implementation using Azure Data Factory (ADF)

## Objective
The objective of this assignment is to understand the basic concepts of Microsoft Azure and build a complete data pipeline using Azure Storage Account and Azure Data Factory.

## Assignment Tasks

### Task 1 - Resource Group
- Explored Azure Portal.
- Created a Resource Group.

### Task 2 - Storage Setup
- Created a Storage Account.
- Created a Blob Container.
- Uploaded a CSV file.

### Task 3 - ADF Basics
- Created Azure Data Factory.
- Explored Author, Monitor, and Manage sections.
- Created Linked Service.
- Created Source and Destination Datasets.
- Used Get Metadata activity.

### Task 4 - Pipeline Development
- Created a pipeline using Copy Data activity.
- Configured source and destination datasets.

### Task 5 - Pipeline Execution
- Executed the pipeline using Debug.
- Verified successful execution.

### Task 6 - IAM Roles
- Assigned Reader role.
- Assigned Contributor role.
- Verified Storage Account access.

### Task 7 - Mini Project
Built a complete Azure Data Factory pipeline that:
- Reads a CSV file from Azure Blob Storage.
- Retrieves metadata using Get Metadata activity.
- Copies the file to a new destination.
- Successfully executes the pipeline.
- Verifies the output in the destination Blob Storage.

## Tools Used

- Microsoft Azure Portal
- Azure Storage Account
- Azure Blob Storage
- Azure Data Factory (ADF)

## Result

The pipeline executed successfully. Metadata was validated, the CSV file was copied to the destination Blob Storage, and all assignment tasks were completed successfully.
